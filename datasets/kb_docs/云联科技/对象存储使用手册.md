# 云联科技 —— 对象存储（COS）使用手册

> 版本：v3.1.0 | 更新日期：2026-04-12

---

## 1. 产品概述

对象存储（Cloud Object Storage，简称 COS）是云联科技提供的高可靠、低成本、安全可扩展的分布式存储服务。COS 采用扁平化命名空间，支持任意类型文件的存储与访问，适用于图片视频存储、数据备份、日志归档、静态网站托管等场景。

**核心特性：**
- 数据持久性：99.9999999999%（12个9）
- 按实际使用量计费，无最低消费
- 全球多地域部署，覆盖国内主要城市及海外节点

---

## 2. 核心概念

### 2.1 存储桶（Bucket）

Bucket 是文件的存储容器，所有文件必须归属于某个 Bucket。

- **命名规则**：全局唯一，长度为 3~63 个字符，只能包含小写字母、数字和短横线（-）。
- **地域**：创建时指定，创建后不可更改。
- **访问权限**：支持私有读写、公有读私有写、公有读写三种级别。

### 2.2 对象（Object）

Object 是 COS 存储的基本单元，一个 Object 由以下三部分组成：

| 组成 | 说明 |
|------|------|
| Key | 对象的唯一标识，即文件名（支持 `/` 模拟目录结构） |
| Data | 文件二进制数据 |
| Metadata | 元数据（Content-Type、Content-Disposition 等 HTTP 头） |

### 2.3 域名（Endpoint）

每个 Bucket 提供以下访问域名：

- **默认域名**：`<BucketName>.cos.<Region>.cloudlink.com`
- **CDN 加速域名**：绑定 CDN 后可获得加速域名
- **自定义域名**：支持绑定备案过的自有域名

## 3. 操作指南

### 3.1 控制台操作

#### 创建 Bucket

1. 登录云联云控制台（https://console.cloudlink.com）。
2. 选择"对象存储"产品，点击"创建 Bucket"。
3. 填写名称、选择地域、设置访问权限。
4. 可选开启日志记录、版本控制、对象锁定。
5. 创建成功后可在 Bucket 列表中查看。

#### 上传文件

1. 进入 Bucket 详情页，点击"上传文件"。
2. 支持单文件（最大 5GB）或文件夹上传。
3. 上传时可设置存储类型（标准存储 / 低频存储 / 归档存储）。
4. 上传完成后自动计算并显示 ETag 值。

#### 文件管理

- **文件预览**：支持图片、文本、PDF 在线预览。
- **文件搜索**：按前缀、后缀、大小、上传时间筛选。
- **批量操作**：支持批量下载、复制、删除、修改存储类型。

### 3.2 SDK 使用示例

#### Python SDK

```python
from cloudlink.cos import CosClient

client = CosClient(secret_id="YOUR_SECRET_ID", secret_key="YOUR_SECRET_KEY")

# 上传文件
response = client.put_object(
    bucket="example-bucket",
    key="images/logo.png",
    filepath="/local/path/logo.png"
)
print(f"File uploaded, ETag: {response['ETag']}")

# 下载文件
response = client.get_object(
    bucket="example-bucket",
    key="images/logo.png",
    filepath="/local/download/logo.png"
)

# 列举文件
objects = client.list_objects(
    bucket="example-bucket",
    prefix="images/",
    max_keys=100
)
for obj in objects['Contents']:
    print(obj['Key'], obj['Size'])
```

#### Java SDK

```java
import com.cloudlink.cos.*;

CosClient client = new CosClient("YOUR_SECRET_ID", "YOUR_SECRET_KEY");

// 上传文件
PutObjectRequest request = new PutObjectRequest("example-bucket", "doc/report.pdf");
request.setFile(new File("/local/report.pdf"));
PutObjectResult result = client.putObject(request);

// 生成预签名 URL（有效期 1 小时）
PresignedUrlRequest urlRequest = new PresignedUrlRequest("example-bucket", "doc/report.pdf");
urlRequest.setExpiration(3600);
String url = client.generatePresignedUrl(urlRequest);
```

### 3.3 CLI 工具使用

```bash
# 安装 COS CLI
pip install cloudlink-cos-cli

# 配置密钥
coscli config --secret-id YOUR_SECRET_ID --secret-key YOUR_SECRET_KEY

# 上传文件
coscli cp /local/data.csv cos://example-bucket/data/

# 下载文件
coscli cp cos://example-bucket/data/report.pdf ./download/

# 同步目录
coscli sync ./images/ cos://example-bucket/images/ --delete
```

## 4. 访问权限管理

### 4.1 Bucket 级别权限

| 权限级别 | 说明 |
|----------|------|
| 私有读写（private） | 需签名认证访问，推荐用于生产数据 |
| 公有读私有写（public-read） | 可匿名读取，仅认证后可写入 |
| 公有读写（public-read-write） | 完全公开，仅用于静态网站等场景 |

### 4.2 访问控制策略（Bucket Policy）

支持基于 JSON 的访问策略，精细控制用户/来源 IP/Referer 对 Bucket 和前缀的访问权限。

```json
{
    "version": "2.0",
    "statement": [
        {
            "effect": "Allow",
            "principal": "*",
            "action": "cos:GetObject",
            "resource": "cos://example-bucket/public/*",
            "condition": {
                "referer": {"string_like": {"cos:Referer": "https://example.com/*"}}
            }
        }
    ]
}
```

### 4.3 临时密钥（STS）

通过云联 STS 服务生成临时密钥，有效期最长 12 小时，适用于移动端或前端直传场景。

## 5. 生命周期管理

支持按时间或大小自动转换存储类型或删除文件。

**规则示例：**
- 创建 30 天后转换为低频存储
- 创建 180 天后转换为归档存储
- 创建 730 天后自动删除

### 存储类型对比

| 类型 | 可用性 | 最低存储天数 | 适用场景 |
|------|--------|-------------|----------|
| 标准存储 | 99.99% | 无 | 频繁访问的热数据 |
| 低频存储 | 99.9% | 30天 | 月均访问 1-2 次的数据 |
| 归档存储 | 99.9% | 90天 | 备份、合规归档数据 |

## 6. 数据安全

### 6.1 服务端加密

- **SSE-COS**：COS 托管密钥，自动加密。
- **SSE-KMS**：使用云联 KMS 服务管理密钥。
- **SSE-C**：用户自持密钥。

### 6.2 版本控制

- 开启后，覆盖写或删除时保留历史版本。
- 可恢复至任意历史版本。
- 删除标记（Delete Marker）可撤销。

### 6.3 跨区域复制

- 将 Bucket 中的数据自动、异步复制到另一地域的 Bucket。
- 支持同账号及跨账号复制。
- 适用于异地容灾、数据合规、就近访问场景。

## 7. 最佳实践

### 7.1 图片处理

COS 集成图片处理服务，支持实时处理参数：

```
https://example-bucket.cos.ap-hangzhou.cloudlink.com/photo.jpg?x-cos-process=image/resize,w_500/quality,q_90
```

支持功能：缩放、裁剪、旋转、水印、格式转换、锐化。

### 7.2 静态网站托管

1. 创建 Bucket，开启"静态网站托管"。
2. 设置首页文档（如 index.html）和错误文档（如 404.html）。
3. 可选绑定 CDN 加速域名。
4. 配置自定义域名和 HTTPS 证书。

### 7.3 跨域资源共享（CORS）

```json
{
    "cors_rules": [
        {
            "allowed_origins": ["https://www.example.com"],
            "allowed_methods": ["GET", "PUT", "POST"],
            "allowed_headers": ["*"],
            "max_age_seconds": 3600
        }
    ]
}
```
