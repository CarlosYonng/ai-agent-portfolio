## 1. Web 应用防火墙（WAF）

### 1.1 产品概述

云联 WAF（Web Application Firewall）基于云端大数据分析引擎，提供对 Web 应用和 API 的全面防护，抵御 SQL 注入、XSS 跨站脚本、CC 攻击、恶意爬虫等常见 Web 攻击。

### 1.2 防护规则

WAF 内置四大类防护规则，默认开启并自动升级：

| 规则类型 | 防护内容 | 默认状态 |
|----------|----------|----------|
| Web 核心防护 | SQL 注入、XSS、命令执行、文件包含、CSRF | 开启 |
| CC 防护 | 高频访问限速、人机验证、滑块验证 | 开启 |
| 恶意爬虫 | 搜索引擎验证、异常 UA 拦截、爬虫指纹识别 | 按需开启 |
| 区域/IP 黑名单 | 地理区域封锁、IP 信誉库匹配 | 按需配置 |

#### 自定义防护规则

支持用户自定义规则，语法结构如下：

```json
{
    "name": "block_sensitive_url",
    "priority": 10,
    "match": {
        "field": "uri",
        "operator": "contains",
        "value": "/admin"
    },
    "action": "block",
    "status": "enabled"
}
```

**匹配字段支持**：URI、Query String、Request Header、POST Body、Cookie、IP。

**动作支持**：放行、拦截、记录、人机验证。

### 1.3 接入配置

#### DNS 接入（CNAME 方式）

1. 在 WAF 控制台添加域名。
2. 获取 WAF 分配的 CNAME 域名。
3. 修改 DNS 解析记录，将域名 CNAME 指向 WAF 域名。
4. 流量自动经过 WAF 清洗后转发至源站。

#### 反向代理接入（修改回源地址）

1. 在 WAF 控制台添加域名并填写源站 IP 地址。
2. 修改源站防火墙策略，允许 WAF 回源 IP 段通过。
3. 业务 DNS 无需变更，WAF 作为反向代理工作。

### 1.4 安全报表

- **攻击概览**：攻击总次数、拦截率、TOP 攻击类型。
- **攻击详情**：攻击者 IP 分布、被攻击 URL 排行、攻击时间线。
- **Bot 分析**：爬虫请求占比、合法/恶意爬虫分布。
- **CC 攻击记录**：触发 CC 防护的请求详情和处罚动作。

## 2. DDoS 防护

### 2.1 产品概述

云联 DDoS 防护（高防 IP）提供 L3–L7 层全方位的分布式拒绝服务攻击防护能力，覆盖各类常见 DDoS 攻击类型。

### 2.2 防护能力

| 防护套餐 | 保底防护 | 弹性防护 | 最大防护 |
|----------|----------|----------|----------|
| 基础版 | 5Gbps | 5~20Gbps | 20Gbps |
| 标准版 | 20Gbps | 20~100Gbps | 100Gbps |
| 专业版 | 100Gbps | 100~300Gbps | 300Gbps |
| 企业版 | 300Gbps | 按需升级 | 1Tbps+ |

### 2.3 L3–L7 层防护策略

#### 网络层（L3/L4）

| 攻击类型 | 防护策略 |
|----------|----------|
| SYN Flood | SYN Cookie、源验证、速率限制 |
| UDP Flood | 流量限速、协议验证、源限速 |
| ICMP Flood | ICMP 速率限制、禁用 ICMP 回显 |
| ACK Flood | 无状态会话验证、异常标记丢弃 |
| DNS 反射放大 | 源端口验证、响应报文限速 |
| NTP/SSDP 反射 | 反射源信誉库、报文特征识别 |

#### 应用层（L7）

- HTTP Flood 防护
- 慢速攻击（Slowloris、Slow Post）
- HTTPS/SSL 洪水攻击
- WebSocket 连接攻击

### 2.4 告警与应急

#### 告警阈值设置

| 指标 | 建议阈值 | 告警动作 |
|------|----------|----------|
| 入带宽 | 保底值的 80% | 短信+邮件+Webhook |
| 连接数 | 基线的 150% | 短信+邮件 |
| 攻击事件 | 发生即触发 | 电话通知 |

#### 应急响应流程

1. **检测**：监控系统自动检测异常流量，触发告警。
2. **确认**：安全工程师确认攻击类型和规模（5 分钟内）。
3. **清洗**：自动开启清洗，牵引攻击流量至清洗中心。
4. **通知**：通知用户攻击详情和已采取的防护措施。
5. **溯源**：攻击结束后生成防护报告，提取攻击特征。

## 3. SSL 证书管理

### 3.1 证书类型

| 类型 | 验证级别 | 颁发时长 | 适用场景 |
|------|----------|----------|----------|
| DV（域名验证） | 低 | 10 分钟~2 小时 | 个人网站、测试环境 |
| OV（组织验证） | 中 | 1~3 个工作日 | 企业官网、电商平台 |
| EV（扩展验证） | 高 | 3~7 个工作日 | 金融、银行、政务平台 |

### 3.2 证书申请流程

#### DV 证书自动申请

1. 登录 SSL 证书控制台，点击"申请证书"。
2. 选择证书类型为"DV"，填写域名。
3. 验证方式选择 DNS 解析 / 文件验证 / 邮箱验证。
4. 自动签发后，支持一键部署到云联产品（CDN、ECS）或手动下载。

#### OV/EV 证书申请

1. 提交证书申请，填写组织信息（公司名称、营业执照号等）。
2. 提交企业资质材料进行组织身份审核。
3. CA 机构电话核实（仅 EV 证书）。
4. 审核通过后颁发证书。
5. 下载证书文件（支持 Apache、Nginx、IIS、Tomcat 等格式）。

### 3.3 证书部署

| 部署场景 | 操作方式 |
|----------|----------|
| CDN 加速 | 控制台"证书管理"→一键部署 |
| ECS 服务器 | 手动下载→服务器配置→重启服务 |
| 负载均衡（SLB） | 控制台监听器配置→选择证书 |
| 对象存储（COS） | 绑定自定义域名→开启 HTTPS→上传证书 |

### 3.4 证书监控与更新

- **到期提醒**：证书到期前 30 天、15 天、7 天、3 天分别发送通知。
- **自动更新**：DV 证书支持自动续签（需保持验证信息有效）。
- **吊销管理**：支持控制台一键吊销证书，吊销后即时生效。

## 4. 安全合规

### 4.1 合规资质

- 等保三级认证（云平台）
- ISO 27001 信息安全管理体系认证
- CSA STAR 认证
- 《个人信息保护法》合规

### 4.2 日志审计

- 所有安全产品操作记录保存至少 180 天。
- 安全事件日志保存至少 1 年。
- 支持日志对接第三方 SIEM 系统（Syslog/HTTP）。

---

> **技术支持**：安全产品 7×24 小时专线 400-168-9999（紧急安全事件优先处理）；非紧急事务通过工单系统提交。
