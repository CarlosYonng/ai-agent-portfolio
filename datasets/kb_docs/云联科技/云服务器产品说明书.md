# 云联科技 —— 云服务器（ECS）产品说明书

> 版本：v2.4.0 | 更新日期：2026-05-20

---

## 1. 产品概述

云服务器（Elastic Compute Service，简称 ECS）是云联科技提供的一种弹性可伸缩的计算服务。用户无需提前采购硬件，即可在数分钟内获得一台或多台云服务器，并按需付费。ECS 适用于网站托管、应用部署、数据分析、容器编排、游戏服务等各类场景。

---

## 3. 计费方式

云联科技 ECS 提供三种计费模式，用户可根据业务需求灵活选择。

### 3.1 包年包月

- **概述**：按月或按年预付费，价格最低。
- **折扣**：1个月基准价；3个月享 9 折；6个月享 85 折；12个月享 8 折；36个月享 65 折。
- **适用场景**：业务稳定的生产环境、长期运行的服务。
- **到期处理**：到期前 7 天发送通知；到期后停机，续费后自动恢复。

### 3.2 按量付费

- **概述**：按小时计费，秒级计费周期，即开即停。
- **价格**：约为包年包月单价的 1.5 倍。
- **适用场景**：突发性计算需求、弹性扩容、测试环境。
- **释放规则**：欠费后进入"欠费锁定"状态，15 天内未充值则自动释放。

### 3.3 抢占式实例

- **概述**：利用闲置资源，按市场浮动价格出售。
- **价格**：最高为按量付费的 20%。
- **适用场景**：容错性强、可中断的任务，如大数据计算、CI/CD 流水线。
- **回收机制**：当资源紧张时，实例可能在 5 分钟通知后被自动回收。

### 3.4 增值服务费用

| 项目 | 计费说明 |
|------|----------|
| 公网带宽 | 按固定带宽或按流量计费 |
| 系统盘快照 | 超过免费额度（20GB）后按快照容量计费 |
| 镜像 | 公共镜像免费；自定义镜像按存储空间计费 |
| 弹性公网 IP | 未绑定实例时按小时收费 |

## 4. 网络与安全

### 4.1 专有网络（VPC）

- 每个 ECS 实例必须归属于一个 VPC。
- VPC 提供逻辑隔离的网络环境，支持自定义 IP 地址段（CIDR）。
- 支持 VPC 间对等连接、VPN 网关接入 IDC。

### 4.2 安全组

- 安全组是一种虚拟防火墙，用于控制实例的入方向和出方向流量。
- 每个实例最多可加入 5 个安全组。
- 支持 5 元组规则（源 IP、源端口、目的 IP、目的端口、协议）。
- **建议**：遵循最小权限原则，仅开放业务必需端口。

### 4.3 弹性公网 IP（EIP）

- 独立购买的公网 IP 地址，可随时绑定或解绑到 ECS 实例。
- 支持 IPv4 和 IPv6。
- 最多可持有 20 个 EIP（可通过工单申请提升配额）。

## 5. 运维管理

### 5.1 远程连接

- **VNC 管理终端**：通过 Web 浏览器直接连接，无需公网 IP，适用于网络不通时应急排查。
- **SSH / RDP**：标准远程登录方式。
- **会话管理（Session Manager）**：基于云联云管平台的安全 Shell，无需开放入方向端口，支持审计日志。

### 5.2 监控与告警

- **基础监控**：CPU 使用率、内存使用率、磁盘 IO、网络流量（1 分钟粒度，免费）。
- **自定义监控**：支持用户上报自定义指标。
- **告警规则**：支持多条件组合告警（如 CPU > 80% 且持续 5 分钟），通知渠道包括短信、邮件、Webhook。
- **操作审计**：记录所有控制台及 API 操作，保留 180 天。

### 5.3 快照与镜像

- **快照**：对云盘进行全量或增量备份，支持自动快照策略（每日/每周）。
- **镜像**：
  - 公共镜像：CentOS、Ubuntu、Debian、Windows Server 等。
  - 自定义镜像：从已有实例或快照创建。
  - 共享镜像：跨账号共享。
- **一键恢复**：从快照或镜像创建新实例，或回滚系统盘。

## 6. 存储

### 6.1 云盘类型

| 类型 | 最大容量 | 最大 IOPS | 适用场景 |
|------|----------|-----------|----------|
| 高效云盘 | 32TB | 3000 | 系统盘、日志存储 |
| SSD 云盘 | 32TB | 26000 | 中型数据库、IO 密集型应用 |
| ESSD 云盘 | 32TB | 1000000 | 大型数据库、高频交易系统 |

### 6.2 云盘操作

- 支持在线扩容（无需停机）。
- 支持挂载/卸载多块云盘。
- 支持创建独立云盘（不随实例释放）。
