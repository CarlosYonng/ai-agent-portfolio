# 云联科技 —— CDN 加速产品说明

> 版本：v2.8.0 | 更新日期：2026-05-08

## 1. 产品概述

云联 CDN（Content Delivery Network）是云联科技推出的内容分发加速服务，依托覆盖全国及海外的分布式边缘节点，将用户请求调度至最近节点响应，显著降低访问延迟、提升用户体验。

**核心优势：**
- 全国 2000+ 加速节点，覆盖电信、联通、移动、教育网
- 海外 500+ 节点，覆盖六大洲主要城市
- 单节点带宽储备 40Gbps+，全网储备 150Tbps+
- 毫秒级动态加速，支持智能路由

## 2. 加速场景

### 2.1 静态加速

- **适用场景**：图片、CSS/JS、字体文件、PDF 等静态资源。
- **缓存策略**：文件类型/后缀/目录粒度配置，支持自定义缓存过期时间。
- **推荐指数**：★★★★★

### 2.2 动态加速（DCDN）

- **适用场景**：API 接口、动态页面、交互性强的 Web 应用。
- **技术原理**：通过智能路由、TCP 优化、连接复用等提升动态请求响应速度。
- **推荐指数**：★★★★☆

### 2.3 下载加速

- **适用场景**：软件安装包、游戏客户端、大文件分发。
- **特性**：支持分片传输、断点续传、大文件预缓存。
- **推荐指数**：★★★★★

### 2.4 视频点播/直播加速

- **适用场景**：短视频、在线教育、直播带货、赛事直播。
- **特性**：支持 FLV/HLS/DASH 等多协议，首屏秒开优化。
- **推荐指数**：★★★★★

## 3. 配置指南

### 3.1 添加加速域名

#### 前置条件

- 已注册并完成实名认证。
- 域名已完成 ICP 备案（中国大陆节点）。
- 源站已正常运行（云联 ECS / COS / 自建源站）。

#### 操作步骤

1. 登录云联 CDN 控制台，点击"添加域名"。
2. **域名填写**：输入需要加速的域名（如 `cdn.example.com`）。
3. **源站配置**：
   - 源站类型：云联 ECS / COS / 自建源站（IP 或域名）。
   - 支持主备源站配置。
   - 支持源站响应超时设置（默认 5 秒）。
4. **加速区域**：中国大陆 / 全球 / 港澳台及海外。
5. **业务类型**：静态加速 / 动态加速 / 下载加速 / 视频点播。
6. 提交审核，审核通过后即可配置 CNAME。

### 3.2 CNAME 解析

1. 控制台获取系统分配的 CNAME 域名（如 `cdn.example.com.cname.cloudlink.com`）。
2. 前往域名 DNS 服务商处添加一条 CNAME 记录。
3. 生效时间通常为 5~30 分钟。
4. 控制台验证状态，"已生效"即完成接入。

### 3.3 缓存规则配置

支持三种粒度配置缓存策略：

| 配置方式 | 示例 | 说明 |
|----------|------|------|
| 文件后缀 | `*.jpg, *.png, *.css, *.js` | 按文件类型 |
| 目录路径 | `/static/*, /assets/images/*` | 按路径前缀 |
| 全路径匹配 | `/index.html, /api/v1/config.json` | 精确文件 |

**缓存过期时间设置建议：**

| 文件类型 | 缓存时长 | 说明 |
|----------|----------|------|
| 图片（JPG/PNG/GIF） | 30 天 | 变更较少，长缓存 |
| CSS/JS | 7~30 天 | 配合版本号或指纹更新 |
| HTML | 0~1 小时 | 频繁更新，短缓存或不缓存 |
| API 响应 | 0 | 不缓存，由动态加速处理 |

### 3.4 HTTPS 配置

- 支持通过控制台一键上传自有 SSL 证书。
- 支持使用云联 SSL 证书管理服务自动签发。
- 支持 HTTP/2 和 OCSP Stapling。
- 支持强制跳转（HTTP→HTTPS、301/302 选择）。

## 4. 监控报表

### 4.1 流量与带宽监控

- **实时监控**：1 分钟粒度展示带宽使用曲线。
- **日/周/月报表**：支持按时间范围查询流量峰值、95 峰值、总流量。
- **地域/运营商分布**：查看各省份及运营商流量占比。

### 4.2 命中率分析

- **字节命中率**：展示 CDN 节点直接响应的字节占比。
- **请求命中率**：展示 CDN 节点直接响应的请求次数占比。
- **行业参考**：图片/静态文件推荐命中率 95%+；动态资源命中率通常较低。

### 4.3 回源统计

- 回源带宽 / 回源请求数 / 回源失败率。
- 回源状态码分布（2xx / 3xx / 4xx / 5xx）。
- 响应超时和重试记录。

### 4.4 日志服务

- 支持小时级日志导出（下载或推送至 COS）。
- 日志字段：时间、客户端 IP、URL、状态码、响应大小、Referer、User-Agent。

## 5. 安全防护

### 5.1 Referer 防盗链

- 支持白名单和黑名单模式。
- 支持空 Referer 放行或拦截。

### 5.2 IP 黑名单

- 封禁指定 IP 或 IP 段的访问。
- 支持 IPv4 和 IPv6。
- 最多可配置 1000 条规则。

### 5.3 URL 鉴权

- **类型 A**：基于时间戳的鉴权 URL，过期后自动失效。
- **类型 B**：基于时间戳 + IP 的鉴权。
- **类型 C**：自定义鉴权密钥和参数名。

## 7. 常见问题排查

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 访问返回 404 | 源站文件不存在或 CNAME 未生效 | 确保证书正常且源站路径正确 |
| 缓存未更新 | 缓存过期时间过长 | 手动刷新缓存（支持 URL 刷新和目录刷新） |
| 访问返回 502 | 源站超时或不可达 | 检查源站状态和防火墙配置 |
| HTTPS 证书错误 | 证书过期或未配置 | 在控制台重新上传或续签证书 |
| 跨地域访问慢 | 节点覆盖不足 | 确认加速区域配置正确 |
