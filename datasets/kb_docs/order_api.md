# 订单创建接口说明

接口：POST /api/orders

订单创建接口用于创建普通商品订单。请求参数包括 userId、skuId、quantity、couponId。

couponId 为可选字段。如果用户没有使用优惠券，调用方可以不传 couponId。

接口处理流程：

1. 校验用户状态。
2. 查询商品库存。
3. 如果 couponId 不为空，则调用优惠券服务校验优惠券。
4. 预占库存。
5. 创建订单。
6. 发送订单创建事件。

常见异常：

- 库存不足会返回 ORDER_4001。
- 优惠券不存在会返回 COUPON_404。
- 支付回调签名失败会返回 PAY_5001。
