# 中文 B2C 帮助中心知识库包

## 用途

这组文档用于模拟“B 端企业产品知识库，供 C 端用户搜索和问答”的场景。内容面向普通用户，不面向开发人员。

文档按帮助中心常见栏目拆分，适合直接登记到知识库系统中做检索增强问答、客服助手、售前售后问答和用户自助服务演示。

## 适合上传到系统的方式

建议创建两个知识库：

1. 京东用户帮助知识库
2. 携程用户帮助知识库

也可以创建一个“综合电商与旅行服务帮助知识库”，把本目录所有 Markdown 文件都上传进去。

京东建议上传文件名以“京东-”开头的文档，覆盖账号登录、下单支付、配送收货、退换售后、发票、优惠券、PLUS 会员、客服、地址修改、价保、礼品卡、白条分期、隐私注销等主题。

携程建议上传文件名以“携程-”开头的文档，覆盖账号订单、机票、酒店、火车票、退改取消、发票报销、优惠券会员、客服、租车接送、门票玩乐、旅行保险、度假套餐、紧急协助等主题。

## 来源说明

本文档包参考中文公开帮助中心常见栏目、服务规则和用户问题类型整理，文案为适合演示的原创归纳，不是对官方页面的逐字复制。
