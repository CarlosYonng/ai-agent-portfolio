# 精智医疗 —— HIS 系统产品说明书

> 版本：v3.5.0 | 更新日期：2026-05-10

---

## 1. 产品概述

精智医疗 HIS（Hospital Information System）是为民营医疗机构量身定制的一体化信息管理系统。系统覆盖患者从挂号、就诊、缴费到取药/住院的全链路流程，帮助医疗机构实现数字化运营管理，提升服务效率和患者满意度。

**核心定位：**
- 面向门诊部、专科诊所、综合医院（100~500 张床位规模）
- 支持多院区一体化管理
- 符合国家电子病历应用水平分级评价标准

## 3. 八大核心模块

### 3.1 挂号管理

- **挂号方式**：窗口挂号、微信公众号预约、自助终端挂号。
- **号源管理**：科室/医生/时段三级号源池管理，支持停诊和替诊。
- **挂号费**：支持普通号、专家号、急诊号等多种级别。
- **挂号单**：支持打印挂号小票、二维码就诊指引。

### 3.2 门诊收费

- **收费项目**：诊疗费、检查费、检验费、药品费、材料费。
- **支付方式**：微信支付、支付宝、医保结算、现金、预存款。
- **日结管理**：每日收费自动汇总，支持应收/实收/差异核对。
- **发票开具**：支持电子发票和纸质发票，可按需打印。

> 详细操作见《收费与结算操作手册》。

### 3.3 药房管理

- **药品目录**：支持药品字典维护、医保目录对照。
- **库存管理**：入库、出库、调拨、盘点、报损。
- **处方发药**：接方→审核→调配→复核→发药五步流程。
- **库存预警**：近效期预警、库存下限预警、滞销提醒。

> 详细操作见《药房管理制度》。

### 3.4 药库管理

- **采购计划**：基于库存下限和安全库存自动生成采购计划。
- **供应商管理**：供应商资质审核、供货评价、账期管理。
- **验收管理**：到货验收单、质检记录、发票核销。
- **价格管理**：采购价、批发价、零售价三级价格体系。

### 3.5 门诊管理

- **就诊流程**：分诊→候诊→叫号→就诊→开具处方/检查/检验。
- **门诊病历**：结构化电子病历，支持模板快速录入。
- **处方开立**：支持西药、中成药、中药饮片处方，支持处方模板。
- **检查/检验申请**：电子申请单直达检验科/影像科。

### 3.6 住院管理

- **入院登记**：预约入院、手续办理、押金收取。
- **医嘱管理**：长期医嘱、临时医嘱、医嘱停止/作废。
- **住院费用**：日清单查询、预交金管理、出院结算。
- **床位管理**：床位状态总览、转床、包床、加床。

### 3.7 检验管理（LIS）

- **样本管理**：条码生成→样本采集→签收→检验→审核→报告发布。
- **检验仪器**：支持主流检验仪器数据自动采集（HL7 协议）。
- **质控管理**：室内质控数据自动记录、失控报警。
- **结果审核**：自动审核规则配置，异常结果自动复测提醒。

### 3.8 电子病历（EMR）

- **病历文书**：门诊病历、入院记录、病程记录、出院记录、手术记录等。
- **模板管理**：按科室/病种配置结构化模板，支持个人模板和科室模板。
- **归档管理**：患者出院后病历自动归档，归档后锁定编辑。
- **质量控制**：时限质控（病案按时完成率）、内容质控（必填项校验）。

> 详细操作见《电子病历使用手册》。

## 4. 门诊就诊流程（标准路径）

```
患者到院 → 挂号/取号 → 分诊台报到 → 候诊 → 医生接诊
    ↓（开立处方/检查/检验）
患者缴费 → 取药/检查/检验
    ↓（需复诊）
回诊签到 → 医生查看报告 → 完成就诊
```

### 关键节点说明

- **号源预约**：支持提前 7 天线上预约，预约后 15 分钟内到院有效。
- **分诊报到**：支持扫码签到，系统自动排队叫号。
- **医生接诊**：HIS 自动调取患者历史病历和检查结果。
- **缴费环节**：支持诊间支付（医生站直接扫码）、窗口缴费、自助机缴费。

---

## 5. 住院流程（标准路径）

```
开具住院单 → 办理入院 → 缴纳押金 → 分配床位 → 住院治疗
    ↓（每天）
医嘱开立 → 医嘱执行 → 费用日结 → 日清单推送
    ↓（出院时）
出院医嘱 → 出院结算 → 病历归档 → 离院
```

## 7. 数据安全与备份

- **数据加密**：患者敏感信息（姓名、电话、身份证号）数据库加密存储。
- **访问控制**：基于角色的权限管理（RBAC），操作全程留痕。
- **备份策略**：每日全量备份 + 每小时增量备份；异地容灾备份。
- **灾备恢复**：RTO ≤ 4 小时，RPO ≤ 30 分钟。
