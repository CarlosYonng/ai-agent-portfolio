# 精智医疗 —— 药房管理制度（内部规章）

> 版本：v2.6.0 | 生效日期：2026-03-15

---

## 1. 总则

### 1.1 目的

为规范精智医疗各合作机构药房药品管理的各环节操作，确保药品质量安全，防止差错事故发生，保障患者用药安全，特制定本制度。

### 1.2 适用范围

本制度适用于精智医疗平台内所有合作医疗机构的药房管理工作，包括门诊药房、住院药房及药库。

### 1.3 基本原则

- **依法管药**：严格遵守《药品管理法》《医疗机构药事管理规定》等法律法规。
- **安全第一**：严格执行药品质量管理流程，杜绝质量事故发生。
- **账实相符**：做到药品库存、处方消耗、财务账目三者一致。

## 2. 药品采购管理

### 2.1 供应商管理

#### 供应商准入条件

供应商必须满足以下条件方可进入合作名录：

1. 持有有效的《药品经营许可证》《药品 GSP 证书》。
2. 营业执照经营范围包含相关药品类别。
3. 无严重违法违规经营记录。
4. 具备冷链配送能力（涉及冷链药品的供应商）。
5. 提供产品授权书（一级代理或厂家直签优先）。

#### 供应商评审

| 评审维度 | 权重 | 评审内容 |
|----------|------|----------|
| 资质合规 | 30% | 证照是否齐全、是否在有效期内 |
| 药品质量 | 35% | 近 1 年产品合格率、质量投诉率 |
| 供货能力 | 20% | 订单响应时效、缺货率、配送准确率 |
| 价格优势 | 15% | 同期市场价格对比 |

- 评审周期：每半年一次。
- 评分 < 60 分：暂停合作，限期整改。
- 连续两次 < 60 分：从合作名录中移除。

### 2.2 采购流程

```
药库预警 → 生成采购计划 → 审批 → 下订单 → 
供应商发货 → 到货验收 → 入库 → 发票核销
```

#### 采购计划

- **常规采购**：系统基于库存下限自动生成《采购计划单》，每月 1 日和 15 日定期审核。
- **紧急采购**：临床急需或突发用药需求，可走加急审批通道（响应时间 ≤ 4 小时）。
- **新品引进**：需经药事管理委员会评审通过后方可采购。

#### 采购量控制

- 安全库存：2 周正常消耗量。
- 最大库存：1 个月正常消耗量（特殊管理药品除外）。
- 近效期控制：距有效期不足 6 个月的药品减少采购量。

## 3. 入库与存储

### 3.1 到货验收标准

药品到货后，验收人员需对以下项目逐一核对：

| 验收项目 | 验收标准 | 异常处理 |
|----------|----------|----------|
| 品种数量 | 与订单一致 | 差异部分联系供应商确认 |
| 包装外观 | 包装完好，无破损、变形、受潮 | 拒收并拍照留证 |
| 标签信息 | 品名、规格、批号、有效期清晰 | 标识不清拒收 |
| 有效期 | 距有效期 ≥ 6 个月（常规药品） | 不合格拒收 |
| 冷链温度 | 2~8℃ 全程冷链记录完整 | 温度超标拒收 |
| 随货单证 | 随货同行单、检验报告书 | 单证缺失追补 |

> 验收双人复核制度：一人初验、一人复核，双方签字确认。

### 3.2 温湿度管理

| 存储类型 | 温度要求 | 湿度要求 | 监测频率 |
|----------|----------|----------|----------|
| 常温库 | 10~30℃ | 35%~75% | 每日 2 次 |
| 阴凉库 | ≤20℃ | 35%~75% | 每日 2 次 |
| 冷藏库 | 2~8℃ | 35%~75% | 连续监测 |
| 冷冻库 | -20℃ 以下 | — | 连续监测 |

- 温湿度监测记录保存不少于 3 年。
- 超限报警：控制室立即报警，值班人员 15 分钟内响应处置。

### 3.3 药品分类存储

药品按以下规则分类分区存放：

| 类别 | 存储标识 | 管理要求 |
|------|----------|----------|
| 普通药品 | 绿色标识 | 按药理分类摆放 |
| 麻醉药品 | 专柜加锁 | 双人双锁管理 |
| 精神药品 | 专柜加锁 | 专人管理 |
| 毒性药品 | 专柜加锁 | 双人验收，专册登记 |
| 冷链药品 | 专用冰箱 | 温度连续监测 |
| 近效期药品 | 黄色标识 | ≤ 6 个月时挂标识并备案 |
| 过期药品 | 红色标识 | 隔离存放，集中销毁 |

### 3.4 有效期管理

- 系统对药品有效期实施动态监控。
- 距有效期 ≤ 6 个月：标记为近效期，优先出库。
- 距有效期 ≤ 3 个月：通知采购部联系供应商退换货。
- 过期药品出库：定性为"严重差错"，追究当班人员责任。

## 4. 处方调配与发药

### 4.1 处方审核

接到处方后，药师须对以下内容进行审核：

| 审核项 | 要点 |
|--------|------|
| 处方合法性 | 处方医师签名/签章是否有效 |
| 药品适宜性 | 诊断与用药是否相符，是否有禁忌证 |
| 用法用量 | 剂量、频次、疗程是否在安全范围内 |
| 重复用药 | 是否有相同或同类药物重复开具 |
| 药物相互作用 | 是否存在严重相互作用 |
| 特殊人群 | 儿童、老年人、孕妇、肝肾功能不全者剂量调整 |

**审核结果处理：**
- 审核通过 → 进入调配环节。
- 审核不通过 → 联系处方医师确认修改。
- 紧急情况 → 可先调配后补手续，但须在处方上注明。

### 4.2 调配操作规范

1. **接方**：系统接收处方，打印配药标签。
2. **取药**：按照标签指示定位到货架位置，遵循"先进先出、近效期先出"原则。
3. **核对**：逐一核对药品名称、规格、数量、批号、有效期。
4. **复核**：另一名药师独立复核调配结果。**复核覆盖率：100%。**
5. **打包**：内服药与外用药分开包装；需冷藏药品配备冰袋。
6. **发药**：
   - 呼叫患者姓名，核实身份（姓名 + 就诊号 + 出生日期三要素确认）。
   - 交代用法、用量、注意事项。
   - 门诊患者执行"唱发"制度（大声朗读药品用法用量以确保患者知情）。

### 4.3 退药管理

#### 可退药情形

| 情形 | 条件 |
|------|------|
| 药品不良反应 | 经医务部确认 |
| 处方错误 | 经处方医师确认 |
| 患者转院/出院 | 住院患者停用药品 |
| 药品质量问题 | 经质控确认 |

#### 不可退药情形

- 已经拆包装的药品。
- 特殊管理药品（麻醉、精神、毒性药品）一经发出概不退换。
- 冷链药品离柜后不予退换。
- 患者自身原因要求退药，且药品已离院。

#### 退药流程

患者/科室申请 → 处方医师确认 → 药房质检 → 扫码退回 → 系统冲减 → 财务退款

## 5. 盘点管理

### 5.1 盘点周期

| 盘点类型 | 频率 | 覆盖范围 |
|----------|------|----------|
| 日盘点 | 每日 | 麻醉药品、精神药品 |
| 周盘点 | 每周 | 近效期药品、冷链药品 |
| 月盘点 | 每月 | 全部药品（抽样不低于 20%） |
| 季度盘点 | 每季度 | 全部药品 100% 盘点 |

### 5.2 盘点流程

1. 打印《盘点表》，注明药品名称、规格、批号、账面库存。
2. 两人一组，一人清点一人记录。
3. 实盘数量与账面数量比对。
4. 发现差异立即复盘确认。
5. 盘盈/盘亏填写《药品盘点差异报告单》。

### 5.3 盘盈盘亏处理

| 差异率 | 处理方式 |
|--------|----------|
| ≤ 0.1% | 财务调整，备案 |
| 0.1%~0.5% | 查明原因，整改报告 |
| > 0.5% | 启动内部审计流程 |

**常见盘亏原因：** 漏记账、错发药品、报损未登记、被盗。

**常见盘盈原因：** 退药未入账、入库重复记账、规格混淆。

## 6. 药品报损与销毁

### 6.1 报损条件

- 过期药品。
- 变质、污染、破损药品。
- 被召回药品（厂家召回或药监部门要求召回）。
- 因存储不当导致质量受损的药品。

### 6.2 销毁流程

1. 填写《药品报损销毁申请表》。
2. 药房负责人审核签字。
3. 医务部和财务部会签。
4. 在药监部门监督下销毁（特殊管理药品）或机构自行销毁（普通药品）。
5. 销毁现场至少两人在场并全程录像。
6. 销毁记录保存不少于 5 年。

## 7. 药房安全管理

### 7.1 人员管理

- 药房工作人员必须持有药学相关专业学历及药师资格证。
- 每年至少参加 2 次药学继续教育培训。
- 新入职员工须完成药房 SOP 培训并通过考核后方可独立上岗。

### 7.2 环境安全

- 药房非工作人员禁止入内。
- 夜间和节假日落实"双人值守"或"视频监控 + 远程值守"。
- 定期检查消防设施、电路安全、冰箱应急电源。

### 7.3 差错管理

| 差错等级 | 定义 | 处理 |
|----------|------|------|
| 轻微差错 | 标签贴错、数量差错但未发药 | 内部记录，月度通报 |
| 一般差错 | 发错药品但被患者/护士发现未服用 | 当事人书面检讨 |
| 严重差错 | 错发药品已服用但未造成明显损害 | 停职培训 + 通报 |
| 重大事故 | 错发药品造成患者伤害或死亡 | 依法追究，终止合同 |

---

> **本制度的解释权归精智医疗质量管理部所有。** 各合作机构须在本制度基础上制定本机构药房管理细则并报备。
