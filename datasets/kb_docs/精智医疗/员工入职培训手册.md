## 前言

欢迎加入精智医疗！本手册旨在帮助新员工全面了解公司概况、快速融入团队，为后续工作打下良好基础。请仔细阅读本手册，并在入职第一周内完成各项培训安排。

## 第一章 公司概况

### 1.1 公司简介

精智医疗（IntelliMed）成立于 2019 年，总部位于深圳，是一家专注于民营医疗机构数字化管理的医疗 SaaS 服务商。公司致力于通过信息化手段帮助诊所、门诊部和综合医院实现高效运营，提升医疗服务质量。

**公司使命**：用科技赋能基层医疗，让每一家民营医疗机构都能拥有世界级的管理系统。

**公司愿景**：成为中国民营医疗数字化管理的第一品牌。

**核心价值观**：
- **客户至上**：以客户需求为导向，持续创造价值
- **精益求精**：追求产品极致体验，细节决定成败
- **合作共赢**：与客户、伙伴、员工共同成长
- **创新驱动**：鼓励创新思维，拥抱变化

### 1.2 发展历程

| 年份 | 里程碑 |
|------|--------|

## 第二章 入职须知

### 2.1 入职手续

新员工报到时需提交以下材料：

| 材料名称 | 要求 | 备注 |
|----------|------|------|
| 身份证 | 原件 + 复印件 1 份 | 核验后归还原件 |
| 毕业证/学位证 | 原件 + 复印件 1 份 | — |
| 离职证明 | 原件 | 上家单位开具 |
| 体检报告 | 3 个月内有效 | 二甲及以上医院 |
| 银行卡信息 | 工资卡复印件 | 深圳本地银行卡优先 |
| 一寸证件照 | 白底，2 张 | 电子版同步提交 |
| 社保/公积金转移 | — | 人力资源协助办理 |

### 2.2 劳动合同

- 合同期限：首次签订 3 年（含 6 个月试用期）。
- 续签：合同到期前 30 天评估，双方协商续签。
- 试用期薪资：正式薪资的 80%。
- 试用期考核目标：入职第 2 周设定，第 4 个月末评估。

### 2.3 试用期管理

#### 试用期阶段安排

| 阶段 | 时间 | 重点内容 |
|------|------|----------|
| 融入期 | 第 1~2 周 | 入职培训、导师分配、团队熟悉 |
| 学习期 | 第 3~8 周 | 岗位技能培训、参与实际工作 |
| 实践期 | 第 9~16 周 | 独立承担任务、阶段性考核 |
| 评估期 | 第 17~24 周 | 试用期总结评估、转正答辩 |

#### 转正条件

1. 完成全部必修培训课程并通过考核。
2. 试用期考核得分 ≥ 70 分（满分 100）。
3. 未发生重大工作失误或违规行为。
4. 通过转正答辩评审。

## 第四章 考勤制度

### 4.1 工作时间

| 项目 | 说明 |
|------|------|
| 工作时间 | 周一至周五 9:00~12:00，13:30~18:30 |
| 弹性空间 | 上班弹性区间 8:30~9:30；下班弹性区间 18:00~19:00 |
| 午餐时间 | 12:00~13:30（含午休） |
| 工作时长 | 每日标准 8 小时 |

### 4.2 打卡管理

- **打卡方式**：企业微信打卡（GPS 定位 + 人脸识别）。
- **打卡范围**：公司办公地址周边 500 米。
- **外勤打卡**：提前申请，上级审批后可在外勤区域打卡。
- **补卡**：漏打卡可在当天 24:00 前申请补卡，每月限 3 次。

#### 迟到/早退处理

| 时长 | 处理方式 |
|------|----------|
| 0~15 分钟 | 月度累计 ≤ 3 次警告提醒，≥ 4 次每次扣 50 元 |
| 15~60 分钟 | 每次扣 100 元 |
| > 60 分钟 | 按半天事假处理 |
| 早退 | 同迟到标准执行 |

### 4.3 请假管理

#### 请假类型

| 类型 | 额度 | 说明 |
|------|------|------|
| 年假 | 5~15 天/年 | 工龄 < 10 年：5 天；10~20 年：10 天；> 20 年：15 天 |
| 事假 | — | 无薪，全年累计 ≤ 20 天 |
| 病假 | — | 需提供医院证明，按日薪 60% 发放 |
| 婚假 | 3 天 | 转正后可享受 |
| 产假 | 128 天 | 按国家相关规定执行 |
| 陪产假 | 15 天 | 男性员工 |
| 丧假 | 3 天 | 直系亲属 |

#### 请假流程

1. 企业微信提交请假申请。
2. 填写请假类型、起止时间、事由。
3. 审批流程：
   - ≤ 3 天：直属上级审批。
   - 3~7 天：部门负责人审批。
   - > 7 天：CEO 审批。
4. 审批通过后同步考勤系统。

### 4.4 加班与调休

- **加班认定**：工作日加班 ≥ 2 小时可申请；周末/节假日加班按实际时长计算。
- **调休**：加班时间按 1:1 比例转为调休时长，有效期为 3 个月。
- **法定节假日加班**：按国家规定发放三倍工资（不调休）。

### 4.5 假期规定

## 第五章 薪酬福利

### 5.1 薪酬构成

```
月收入 = 基本工资 + 岗位工资 + 绩效奖金 + 补贴 - 社保扣款 - 个税
```

| 项目 | 说明 |
|------|------|
| 基本工资 | 按照岗位职级标准确定 |
| 岗位工资 | 体现岗位价值和技能差异 |
| 绩效奖金 | 月绩效（0~1.5 倍基数），依据 KPI 达成率 |
| 餐补 | 20 元/工作日 |
| 交通补贴 | 200 元/月（有通勤需求岗位） |
| 通讯补贴 | 100 元/月（销售/实施岗位） |

### 5.2 年度奖金

- **年终奖**：根据公司年度经营目标和员工年度绩效评定，通常为 1~3 个月基本工资。
- **项目奖金**：里程碑项目或重要版本发布后的额外奖励。

### 5.3 福利保障

| 福利 | 说明 |
|------|------|
| 五险一金 | 按深圳市规定基数缴纳 |
| 补充商业保险 | 意外险、重疾险（入职即享） |
| 年度体检 | 每年 1 次，公司统一安排 |
| 团建活动 | 每季度 1 次，部门或公司层面 |
| 学习基金 | 每人每年 2000 元（购买书籍/课程） |
| 节日福利 | 春节/中秋/端午礼品或礼金 |
| 生日福利 | 生日当月发放生日券 200 元 |

## 第六章 行为规范

### 6.1 办公规范

- 着装整洁得体，办公区保持安静。
- 会议室使用后需及时清理，白板擦净。
- 工作日午餐不饮酒（商务接待除外）。
- 节约用电用水，最后离开人员关闭灯和空调。

### 6.2 信息安全

- 系统账号为个人专用，严禁转借他人。
- 客户数据和公司内部文档未经授权不得外传。
- 离职时须归还所有公司资产并签署保密承诺书。

### 6.3 沟通规范

- 内部沟通推荐使用企业微信，重要事项使用邮件留档。
- 同事之间相互尊重，禁止语言攻击或歧视性言论。
- 跨部门沟通时遵循"先对口沟通，再升级协调"原则。

## 第七章 培训与发展

### 7.1 新员工培训课程

| 模块 | 课程内容 | 时长 | 完成时限 |
|------|----------|------|----------|
| 公司文化 | 公司介绍、组织架构、规章制度 | 2 小时 | 入职第 1 周 |
| 产品介绍 | HIS/EMR 系统产品概览 | 4 小时 | 入职第 1 周 |
| 岗位技能 | 按岗位划分的专业技能培训 | 8~16 小时 | 入职第 2 周 |
| 工具使用 | 办公工具、开发工具、协作平台 | 4 小时 | 入职第 2 周 |
| 安全培训 | 信息安全、操作规范、保密协议 | 2 小时 | 入职第 1 周 |

### 7.2 导师制

每位新员工入职时将分配一名导师：

- 导师职责：解答疑问、指导工作、定期反馈。
- 辅导周期：入职前 3 个月。
- 沟通频率：每周至少 1 次 1v1 沟通。

### 7.3 晋升通道

```
专业通道：初级 → 中级 → 高级 → 专家 → 资深专家
管理通道：组长 → 主管 → 经理 → 总监 → VP
```

- **晋升评估**：每半年一次（6 月和 12 月）。
- **评估维度**：绩效结果（60%）+ 能力评估（30%）+ 价值观（10%）。
