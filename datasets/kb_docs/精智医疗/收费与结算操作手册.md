# 精智医疗 —— 收费与结算操作手册

> 版本：v2.4.0 | 更新日期：2026-04-05

---

## 1. 产品概述

收费与结算是精智医疗 HIS 系统的核心流程之一，覆盖门诊收费、住院收费、日结管理、退费处理和发票管理等业务环节。本手册旨在帮助收费岗位人员快速掌握系统操作，规范收费行为，防范财务风险。

---

## 2. 门诊收费

### 2.1 收费标准配置

收费项目由系统管理员在"基础数据→收费标准"模块中统一维护：

| 项目类别 | 定价依据 | 更新频率 |
|----------|----------|----------|
| 挂号费 | 机构自主定价 | 按需调整 |
| 诊疗费 | 物价部门核准 | 省级调价后更新 |
| 检查费 | 设备成本 + 耗材 | 按需调整 |
| 检验费 | 耗材 + 人工 | 按需调整 |
| 药品费 | 采购价 ×（1 + 加成率） | 随采购价变动 |
| 材料费 | 采购价 ×（1 + 加成率） | 随采购价变动 |

### 2.2 收费操作流程

#### 门诊收费窗口

```
患者持处方/检查单 → 收费员扫码 → 
系统自动计算费用 → 选择支付方式 → 
收款 → 打印收据/发票 → 患者取药/检查
```

**操作步骤：**

1. **调取待收费项目**：输入患者就诊号或扫描处方条形码，系统自动列出待收费项目。
2. **费用核对**：
   - 核对项目名称、数量、单价、金额。
   - 检查医保统筹支付和个人自付金额（如有医保）。
   - 确认是否有折扣或减免（需提前授权）。
3. **选择支付方式**。
4. **完成收费**。
5. **打印凭证**。

#### 诊间支付（医生站）

医生开具处方/检查单后，患者可直接在医生站扫码支付：

- 医生站展示支付二维码。
- 患者使用微信/支付宝扫码完成支付。
- 支付成功后，处方自动发送至药房，患者直接前往取药/检查。

### 2.3 支付方式

| 支付方式 | 到账时效 | 手续费 | 说明 |
|----------|----------|--------|------|
| 微信支付 | 实时 | 0.38% | 支持付款码和扫码 |
| 支付宝 | 实时 | 0.38% | 支持付款码和扫码 |
| 医保个人账户 | 实时 | — | 仅限医保定点机构 |
| 医保统筹 | T+1 | — | 需医保对账接口 |
| 现金 | 即时 | — | 柜面收取 |
| 预存款扣款 | 实时 | — | 从患者预存账户扣除 |
| 银联刷卡 | T+1 | 0.5% | 支持借记卡和信用卡 |
| 机构转账 | T+3 | — | 单位结算客户 |

### 2.4 医保结算（定点机构专用）

#### 操作流程

1. 收费时选择"医保结算"。
2. 读取医保卡（刷卡或电子医保凭证扫码）。
3. 系统自动将费用明细上传至医保系统。
4. 医保系统返回统筹支付金额、个人账户支付金额和自付金额。
5. 患者确认支付信息。
6. 完成支付，打印医保结算单。

#### 注意事项

| 注意项 | 说明 |
|--------|------|
| 医保目录 | 仅医保目录内项目可走统筹报销 |
| 门槛费 | 年度内自付未达门槛时，需先自付 |
| 封顶线 | 超出年度封顶线的部分需自费 |
| 异地就医 | 需提前备案方可异地直接结算 |
| 医保对账 | 每日日结数据需与医保系统对账 |

## 3. 住院收费

### 3.1 入院押金

- **押金标准**：
  - 无医保患者：预估费用的 100%。
  - 有医保患者：预估自付部分的 100% + 少许溢缴款。
- **缴纳方式**：现金、微信、支付宝、刷卡、银行转账。
- **最低押金**：不低于 1000 元（标准病房）或 3000 元（VIP 病房）。
- **追加押金**：当余额低于预估费用的 30% 时，系统自动推送催缴通知。

### 3.2 住院日清单

- 每日 20:00 自动生成当日费用清单。
- 清单内容：项目名称、单价、数量、金额、医保支付状态。
- 推送渠道：微信公众号 / 病区自助查询终端 / 护士站打印。
- 患者对清单有疑问时，护士或收费员协助核查解释。

### 3.3 出院结算

#### 结算流程

1. 医生下达出院医嘱，系统标记患者"待结算"。
2. 护士核对费用（是否有遗漏操作、未停止的医嘱）。
3. 患者/家属到住院收费窗口办理结算。
4. 收费员调取患者住院费用汇总。
5. 核算总费用 - 已付押金 = 应补退金额。
6. 多退少补，打印《住院费用结算单》。
7. 打印住院发票，完成出院。

#### 特殊情况处理

| 情况 | 处理方式 |
|------|----------|
| 欠费 | 补足欠费后办理 |
| 医保未审批 | 先自费结算，医保审批后手工报销 |
| 生育保险 | 按生育保险政策结算（需提供相关证件） |
| 民政救助 | 先走医保结算，剩余部分走民政救助通道 |

## 4. 日结管理

### 4.1 日结操作步骤

收费员每日下班前必须完成日结，操作流程如下：

1. 在系统中选择"日结管理"→"新建日结单"。
2. 系统自动汇总当前班次的收费数据：
   - 收费总笔数、总金额。
   - 各支付方式的金额分布。
   - 退费笔数及金额。
3. 核对系统数据与实际收款金额是否一致：
   - 现金：清点现金实收金额。
   - 微信/支付宝：核对系统记录与收款到账通知。
   - 医保：核对系统记录与医保结算清单。
   - 银联：核对系统记录与 POS 机交易明细。
4. 若存在差异：填写差异原因，上报财务主管。
5. 确认无误后提交日结。
6. 打印《日结报表》签字确认，与现金一起封包提交财务。

### 4.2 差异处理流程

| 差异类型 | 处理方式 |
|----------|----------|
| 实收 > 应收 | 确认是否找零错误或重复收费；多余金额登记"长款"并存档 |
| 实收 < 应收 | 排查是否漏收、找零失误；确认短款由当事人补足 |
| 支付方式错位 | 核对每笔交易记录修正 |

- 差异金额 > 100 元：除当事人说明外，需当班主管复核。
- 差异金额 > 500 元：启动财务专项调查。

### 4.3 日结报表

日结后系统自动生成以下报表：

- **《收费员日结汇总表》**：收费员逐笔明细。
- **《科室收入日报表》**：按科室汇总当日收入。
- **《支付方式汇总表》**：按支付方式分项汇总。
- **《医保结算日报表》**：医保交易汇总（仅医保定点机构）。

## 5. 退费操作

### 5.1 退费申请流程

```
患者提出退费 → 原开单医生确认 → 科室主任审批（金额>阈值时）→
收费窗口办理退费 → 退款到账 → 系统冲销
```

### 5.2 各类型退费操作细则

#### 门诊退费

| 退费类型 | 前提条件 | 退款路径 |
|----------|----------|----------|
| 药品退费 | 药品未离柜、包装完整 | 原路退回 |
| 检查/检验退费 | 尚未执行 | 原路退回 |
| 挂号退费 | 未就诊或就诊后 30 分钟内 | 原路退回 |
| 预存款退余额 | 患者要求 | 原路退回或现金退款 |

#### 住院退费

- **出院结算后退费**：系统自动以"多退少补"处理。
- **住院期间退费**：
  - 停医嘱 → 系统自动停止计费。
  - 已扣费未执行的项目：执行退费冲销。

### 5.3 退费注意事项

| 序号 | 注意事项 |
|------|----------|
| 1 | 退费金额原则上原路退回（支付宝退到支付宝、微信退到微信） |
| 2 | 现金支付的退费可以现金退款，大额退费（≥ 1000 元）需双人核签 |
| 3 | 医保支付的退费，医保统筹部分需通过医保系统发起退费 |
| 4 | 退费时间超过 T+7 天的，需财务主管审批 |
| 5 | 每笔退费需在系统备注栏写明退费原因（必填） |
| 6 | 同一天同一患者退费超过 3 次系统自动触发预警 |

## 6. 发票管理

### 6.1 发票开具

- **电子发票**（默认）：缴费完成后自动开具，患者可通过微信公众号查看和下载。
- **纸质发票**（按需）：患者凭缴费凭证在收费窗口打印。

#### 发票内容规范

| 字段 | 说明 |
|------|------|
| 发票抬头 | 患者姓名（默认）或单位名称（需提供纳税人识别号） |
| 项目名称 | 挂号费 / 诊疗费 / 西药费 / 中药费 / 检查费 / 检验费等 |
| 金额 | 实际支付金额（大写 + 小写） |
| 开具日期 | 缴费日期 |
| 收款单位 | 医疗机构注册名称 + 税号 |

### 6.2 发票作废

**适用情形：**
- 发票内容打印错误。
- 当天退费。
- 患者要求重开。

**操作流程：**
1. 在系统中找到对应发票记录。
2. 点击"发票作废"，系统自动将发票标记为作废。
3. 纸质发票需收回原件并加盖"作废"戳记。
4. 作废操作需双人授权（收费员 + 主管）。

### 6.3 发票红冲

**适用情形：**
- 非当日退费（隔日退费时需红冲原发票）。
- 患者联发票遗失后的退费。

**操作流程：**
1. 系统发起红冲申请，填写红冲原因和对应原发票号码。
2. 财务主管审核通过。
3. 系统生成红字发票（金额为负数）。
4. 重新开具正确的发票。

## 7. 收费稽核

### 7.1 日常稽核

- 收费员操作日志每日自动导出。
- 财务部每日抽查前一日 10% 的收费单据。
- 重点关注：退费率 > 5% 的收费员、单笔大额现金收费、频繁的发票作废。

### 7.2 月度对账

每月 1 日对上月全部收费数据进行对账：

- 系统应收 vs 财务实收。
- 银行到账流水对账（微信、支付宝、银联）。
- 医保结算费用对账。
- 预存款账户余额对账。
